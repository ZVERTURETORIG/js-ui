# Модуль 11

Список дел находится в папке `todo`, остальные задания — в папке `hw11`.

Запустите локальный сервер из этой папки:

```bash
npx serve .
```

Откройте страницы:

- `http://localhost:3000/todo/`
- `http://localhost:3000/hw11/bill/`
- `http://localhost:3000/hw11/rates/`
- `http://localhost:3000/hw11/signup/`
- `http://localhost:3000/hw11/catalog/`
